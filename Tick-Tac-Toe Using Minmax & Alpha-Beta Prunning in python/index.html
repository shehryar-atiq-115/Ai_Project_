Inside the Engine

How the AI thinks.

A visual guide to adversarial search, evaluation, and pruning.

01

Generate the game tree

Every legal move becomes a branch. The search continues until it reaches a win, loss, or draw.

02

Evaluate outcomes

Wins score positively, losses negatively, and draws zero. Depth rewards faster wins and delayed losses.

03

Maximize, then minimize

The AI chooses the highest score while assuming its opponent will always choose the lowest response.

04

Prune irrelevant branches

Alpha-beta bounds skip paths that cannot change the decision, preserving the same optimal result.

CORE ALGORITHM

Minimax with alpha–beta pruning

Hard mode searches the complete reachable game tree. Because Tic-Tac-Toe has a finite state space, perfect play guarantees the AI will win or draw — never lose.

TIME COMPLEXITYO(bd)
SPACE COMPLEXITYO(d)
UTILITY−10 → +10
function minimax(board, depth, maximizing, α, β):
  if board is terminal:
    return evaluate(board, depth)

  if maximizing:
    best = −∞
    for each legal move:
      best = max(best, minimax(next, depth + 1, false))
      α = max(α, best)
      if β ≤ α: # prune branch
        break
    return best

  else:
    best = +∞
    for each legal move:
      best = min(best, minimax(next, depth + 1, true))
      β = min(β, best)
      if β ≤ α: break
    return best
